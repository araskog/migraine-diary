# Domain Glossary

Use these product terms consistently in specifications, UI text, code, and tests.

| Term | Meaning |
|---|---|
| User | A person with an application account and access to their own diary. |
| Diary date | The calendar date to which a diary entry belongs. |
| Migraine day | A date on which the user reports experiencing migraine. It is not an automated diagnosis. |
| Diary entry | A saved record belonging to one user and one diary date. |
| Missing entry | No entry exists for the user/date. This does not establish that they were migraine-free. |
| Migraine-free day | A day explicitly reported as migraine-free; never inferred from a missing entry. |

Do not use “migraine attack” interchangeably with “migraine day”: counting dates does not establish the number of attacks.
